블로그 초안 자동 생성 기능을 개발하는 중이다. IBM Granite을 사용하여 블로그 초안을 자동으로 생성하는 기능을 구현했다. 

### 블로그 초안 자동 생성

블로그 초안 자동 생성 기능을 개발하면서 Hack 언어를 주로 사용했다. 이 기능을 구현하기 위해 src/blog/posts/2026-08-03-ai-draft.md 파일을 수정했다. 

이 기능을 개발한 이유는 추측이지만, 블로그 글을 작성하는 과정을 자동화하여 시간을 절약하고자 한 것 같다. 블로그 글을 작성하는 과정을 자동화하는 기능을 개발하는 것은 블로그 운영을 편리하게 하기 위한 노력인 것 같다.
