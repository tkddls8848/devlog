IBM은 23건의 제품 문서를 갱신했습니다. 갱신된 제품은 IBM CL/SuperSession for z/OS, IBM Information Management System, IBM Application Delivery Foundation for z Systems, IBM Tivoli OMEGAMON XE for DB2 on z/OS, IBM InfoSphere Optim Data Growth Solution for z/OS, IBM CICS Interdependency Analyzer for z/OS, IBM Z NetView, IBM Observability by Instana Application Performance Monitoring on z/OS, IBM Z Application Performance Management Connect, IBM Z Anomaly Analytics with Watson, IBM Tivoli Composite Application Manager for Transactions for z/OS, IBM Z NetView for Continuous Availability, IBM Db2 Performance Solution Pack for z/OS, IBM Z Service Automation Suite, 등입니다.

Lenovo는 3건의 제품 문서를 갱신했습니다. 갱신된 제품은 Lenovo ThinkSystem SR665 V3 Server, Lenovo Configuration Guide for Confidential Computing and Microsoft CVM, Modernize Microsoft SQL Server 2025 with Lenovo입니다.

HPE는 4건의 제품 문서를 갱신했습니다. 갱신된 제품은 HPE ProLiant DL360 Gen11 QuickSpecs, HPE ProLiant DL145 Gen11 QuickSpecs, HPE 25G and 100G Transceivers QuickSpecs, AMD Accelerators For HPE ProLiant Servers QuickSpecs입니다.

이번 갱신에는 IBM의 z/OS 관련 제품 문서가 주를 이루며, Lenovo와 HPE의 서버 및 관련 제품 문서도 갱신되었습니다.
